# Pachet WebForm — 16 reclame pentru instalatori

Deschide `galerie.html` pentru toate imaginile și textele.

- 16 PNG-uri originale, fundal opac, format portret apropiat de 4:5; dimensiunile exacte sunt în `imagini-surse.json`.
- `16-reclame-complete.md`: texte, 32 hook-uri alternative, briefuri, surse de afirmații și prompturile finale.
- `texte-reclame.csv`: texte structurate pentru copiere; nu este un fișier garantat compatibil cu importul automat Meta.
- `continuari.html`: 15 continuări editoriale, pregătite dar nepublicate. Reclama 16 se referă la pagina de instalații din proiect.
- `concepte.json`: sursa editabilă a conceptelor.

Generare: ImageGen integrat. Designul actual este preluat din REDESIGN_NOTES.md, app/globals.css și reclamele existente: crem, cărbune, portocaliu. DESIGN.md descrie o variantă anterioară.

Publicare: nu s-au lansat reclame, nu s-a cheltuit buget și nu s-au publicat paginile. Înainte de lansare, fiecare reclamă trebuie legată la continuarea corectă publicată, iar oferta live verificată. Nu utiliza imaginile generate drept portofoliu real de instalații.
